# Sentinel Evidence

This repository contains the protocol-owned authoritative security-advisory
artifacts used by the Sentinel GenLayer demonstration.

Objective transaction facts are independently authenticated from the canonical
GenLayer Studio Next RPC (`https://studio-next.genlayer.com/api`). This
repository provides protocol authorization and
remediation context.

consensus, contract execution, and target-state verification.
